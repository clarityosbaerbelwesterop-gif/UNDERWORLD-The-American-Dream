# External Asset Sources & Licenses

All third-party meshes, morph targets, rigs, skinning weights, textures, and motion-capture files used by the UNDERWORLD asset pipeline are strictly **CC0 1.0 Universal (Public Domain)** or **CC-BY 4.0** (commercial use explicitly permitted). Any asset with unclear, non-commercial (NC), or restrictive licensing is rejected.

Raw downloaded source archives live exclusively in `.cache/uwp_sources/` (listed in `.gitignore`) and are fetched reproducibly via `python3 Tools/underworld_pipeline/fetch_sources.py`. Only game-ready derived outputs (`.blend`, `.glb`, baked/packed textures) are committed via Git LFS.

## Procedurally Generated Content (in-house, no third-party licence)

Everything below is generated by `Tools/underworld_pipeline/` at build time. It contains no
third-party asset data, so no external licence applies; copyright is the project's.

| Generated thing | Built by | Notes |
|---|---|---|
| Prop label atlases (street names, signage, invented brands such as "Sundown Cola", "The Hollow Herald") | `props/kit.py` (`text_image`, `_build_label_atlas`) | Text rasterised with the system font DejaVu Sans Bold (Bitstream Vera / DejaVu licence, free use incl. commercial; the font file itself is not shipped). All names are invented for UNDERWORLD. |
| Procedural skin maps (diffuse/normal/roughness), incl. lips, beard stubble, skin fade, brow scar | `characters/procedural_assets.py` (`skin_maps`), `characters/pbr_textures.py` (`build_hero_skin_material`) | Used whenever the CC0 `skins01/02` packs are not on disk (they are unreachable from this sandbox — see `Docs/TOOLCHAIN_SANDBOX.md`). Generated from a seed, tinted by `Config/Characters/*.json` `skin.tint_rgb`. |
| Hairline / skin-fade mask, crown fill | `characters/pbr_textures.py` (`hairline_z`, `crown_fill`) | Painted into the skin map from the morphed head's landmarks. |
| Hair / beard cards and their strand atlas | `characters/hair_beard.py`, `procedural_assets.py` (`strand_atlas`) | Cards are planted on the BVH of the morphed head; the atlas is drawn per cell. |
| Eyebrows / eyelashes (when the CC0 MakeHuman cards are absent) | `characters/face_details.py` (`build_brows`), `pbr_textures.py` (`build_brows_and_lashes_material`) | Same strand-atlas path, one strand per card cell. |
| Face/clothing fold detail, fabric weave, AO | `characters/procedural_assets.py` | Seed-driven, no bitmaps read. |
| Animation clips | `characters/animations.py` (+ CC0 BVH from `.cache/uwp_sources/mocap`) | Procedural clips keyed on the 53-bone rig; the walk is mocap-informed (CC0 BVH source listed above). |

**Licence status of the MakeHuman skin packs:** the `skins01/skins02` diffuse/normal/specular
maps that the pipeline prefers are CC0 and listed in the table above. They are *not* in the repo
(2K binaries, and the host is unreachable from this sandbox), so shipped characters currently use
the procedural maps, which is why `[PBR] procedural skin maps ... - CC0 photo skin unavailable`
appears on every build. If the packs are dropped into `.cache/uwp_sources/`, the photo path is
used automatically and no code change is needed.

## Verification Notes
- **MPFB2 / MakeHuman license split verified** directly from `makehumancommunity/mpfb2/LICENSE.md` (§B GPLv3 source code vs §C CC0-1.0 bundled assets vs §D explicit statement that generated models/exports contain no program logic and are unrestricted user data). Our pipeline imports **zero** GPLv3 MPFB2 code; `Tools/underworld_pipeline/characters/mh_loader.py` is a clean-room reader operating solely on the CC0 `.obj`, `.target.gz`, `.mhclo`, and `.json` asset files.
- **Poly Haven** releases all textures, HDRIs, and models strictly under **CC0 1.0 Universal** (`https://polyhaven.com/license`).
- **Rejected sources**: Any non-commercial (CC-BY-NC), Mixamo/Adobe EULA-restricted, or unlicensed scraped meshes/textures are strictly excluded.
