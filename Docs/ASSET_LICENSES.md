# External Asset Sources & Licenses

All third-party meshes, morph targets, rigs, skinning weights, textures, and motion-capture files used by the UNDERWORLD asset pipeline are strictly **CC0 1.0 Universal (Public Domain)** or **CC-BY 4.0** (commercial use explicitly permitted). Any asset with unclear, non-commercial (NC), or restrictive licensing is rejected.

Raw downloaded source archives live exclusively in `.cache/uwp_sources/` (listed in `.gitignore`) and are fetched reproducibly via `python3 Tools/underworld_pipeline/fetch_sources.py`. Only game-ready derived outputs (`.blend`, `.glb`, baked/packed textures) are committed via Git LFS.

## Verification Notes
- **MPFB2 / MakeHuman license split verified** directly from `makehumancommunity/mpfb2/LICENSE.md` (§B GPLv3 source code vs §C CC0-1.0 bundled assets vs §D explicit statement that generated models/exports contain no program logic and are unrestricted user data). Our pipeline imports **zero** GPLv3 MPFB2 code; `Tools/underworld_pipeline/characters/mh_loader.py` is a clean-room reader operating solely on the CC0 `.obj`, `.target.gz`, `.mhclo`, and `.json` asset files.
- **Poly Haven** releases all textures, HDRIs, and models strictly under **CC0 1.0 Universal** (`https://polyhaven.com/license`).
- **Rejected sources**: Any non-commercial (CC-BY-NC), Mixamo/Adobe EULA-restricted, or unlicensed scraped meshes/textures are strictly excluded.
