# Reference boards

Every important asset needs a board here before high-quality modelling starts (`Docs/QUALITY_GATE.md` §1).

```
Docs/ArtDirection/References/<asset>/
  SOURCES.md          # every image, its origin URL or repo path, and license
  <images>
```

Do not put unlicensed scrapes in this tree. CC0, CC-BY (credit in SOURCES.md), or original UNDERWORLD concept art only.

Jason’s binding concept art already lives in `Docs/ArtDirection/Concepts/` and is linked from `SK_Jason/SOURCES.md`. Other hero assets (Sam, pistol, sedan, LA kit) still need boards — until they do, they cannot pass the quality gate.
