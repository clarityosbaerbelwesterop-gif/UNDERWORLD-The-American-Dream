# UNDERWORLD Vehicle Pipeline (`T-ART-04`)

Spec-driven headless Blender 5.2 automotive generator (`Tools/underworld_pipeline/vehicles/build_vehicle.py`), exporting `VehicleBody3D`-compatible `.glb` hierarchies with damage-ready panels, hinged doors, wheel-center origins, and wheel-arch-safe convex collision.

## Usage
```bash
Tools/uwp build-vehicle Config/Vehicles/VH_Sedan_01.json
Tools/uwp export Blender/Source/Vehicles/VH_Sedan_01/VH_Sedan_01.blend
```

## Contract & Hierarchy (`VH_Sedan_01`)
- **Dimensions**: Original late-90s American full-size sedan (~5.0 × 1.88 × 1.44 m, zero real brands/badges). Faces Blender `-Y` → Godot `+Z`; tires rest on `z = 0.000`.
- **Nodes**: `Body` (subdivided lower body tub: clearcoat metallic paint, chrome grille, headlights, taillights), `Cabin` (greenhouse/roof + glass + mirrors, separate un-subdivided mesh – Bot 1 fix 2026-11-22: inside the subsurf'd Body it collapsed into a crumpled blob), detachable panels (`Hood`, `Trunk`, `Bumper_F`, `Bumper_R`), hinged doors (`Door_FL`, `Door_FR`, `Door_RL`, `Door_RR` pivoted at front vertical hinge edges), and 4 separate wheels (`Wheel_FL`, `Wheel_FR`, `Wheel_RL`, `Wheel_RR` pivoted at exact wheel centers).
- **VehicleBody3D Parameters (stored as glTF extras)**: `wheel_radius_m = 0.34`, `wheelbase_m = 2.86`, `track_width_m = 1.58`.
- **Sockets**: `SOCKET_Seat_Driver`, `SOCKET_Seat_Passenger`, `SOCKET_Exit_Left`, `SOCKET_Exit_Right`, `SOCKET_Headlight_L/R`, `SOCKET_Taillight_L/R`.
- **Collision**: Authored wheel-arch-safe convex hull `UCX_VH_Sedan_01-convcolonly` (clears underside `z >= 0.32 m` for `VehicleWheel3D` suspension raycasts).
- **Budget**: ≤ 60,000 tris LOD0 + auto LOD1/LOD2 generated by `Tools/uwp`. Current v0: 3,382 tris (blockout grade; panels float ~1–2 cm above the tub, no interior).
